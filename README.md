# JobTracker

Monorepo containing a Node/Express backend (`jobTrackerBackend`) and a React Native frontend (`JobTrackerFrontend`).

Quick start:

- Backend: see `jobTrackerBackend/package.json` and `server.js`.
- Frontend: see `JobTrackerFrontend/package.json` and `App.js`.

Ignore files: `.env`, `node_modules`, build artifacts.
